Limo’s New Secrets

In development2.5D platformer

A fan tribute to Milon’s Secret Castle (Hudson Soft, NES, 1986)

The castle is rebuilt in real 3D behind a locked side-on camera, so it parallaxes while it plays like the flat original. Movement, jumps and bubbles are matched to frame-by-frame measurements of the original game, and every block and enemy is built in code.

What makes them different

Three things every game does

  • One idea, all the way down

    Each original stands on a single rule, like whatever you draw becomes true, and every level pushes that rule somewhere new.

  • Plays with whatever’s in your hand

    The originals play with one pointer, so a finger, a mouse and a trackpad all work the same way. The tributes take a keyboard, a gamepad or touch.

  • Built in code, tuned to the frame

    We build almost everything in code instead of importing art. The tributes are measured frame by frame against the originals, then rebuilt in real 3D.

The studio

Small team. Deep systems.

We’re a tiny independent studio, which means we get to be stubborn about the parts that matter. Our games are built from real systems rather than set dressing, the controls have to feel right on a phone as well as a desktop, and when we pay tribute to a classic, we measure it before we rebuild it.

We started on Roblox, where we still run three live worlds and drop in as Egos to run events from inside them. Everything new ships natively.
